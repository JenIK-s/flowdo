# FlowDo 3.0

Быстрый и красивый менеджер задач для Windows. Нативное приложение на **Tauri 2 (Rust) + Svelte 5 + TypeScript**: exe весит несколько мегабайт, стартует мгновенно, данные хранятся локально в SQLite.

## Возможности

- **Умный ввод** с подсветкой прямо в строке: `Отчёт клиенту !срочно #работа @пт`
  - приоритет: `!низкий` `!высокий` `!срочно`, `!0–!3`, `!!` / `!!!`
  - теги: `#тег`
  - срок: `@сегодня` `@завтра` `@послезавтра` `@пн…@вс` `@+3` `@25.12` `@2026-12-31` `@неделя`
- **Разделы**: Сегодня (с просроченными), Предстоящие (по дням), Входящие, Все, Выполненные, проекты с цветами.
  Счётчики и прогресс считаются **для текущего раздела**.
- **Панель задачи**: название, срок с календарём, приоритет, проект, теги, подзадачи с прогрессом, заметки — всё сохраняется автоматически.
- **Палитра команд** `Ctrl K`: поиск задач, переходы, действия, создание задачи прямо из поиска.
- **Перетаскивание**: порядок задач и проектов; задачу можно бросить на проект, «Сегодня» или «Выполненные» в боковой панели.
- Контекстное меню по правому клику, переименование двойным кликом, отмена удаления и выполнения.
- Анимации: выполнение с «салютом» в чекбоксе, конфетти, когда раздел закрыт полностью, плавные перестановки.
- Аналитика (выполнено по дням, серия дней, прогресс проектов), журнал изменений.
- Тёмная/светлая/системная тема, 6 акцентных цветов, экспорт JSON/CSV (Excel) и импорт.
- Данные версии 2.x (Python) переносятся автоматически при первом запуске.

### Горячие клавиши
| Клавиша | Действие |
|---|---|
| `Ctrl K` | Поиск и команды |
| `N` | Новая задача |
| `↑ ↓` / `J K` | Выбор задачи |
| `Space` | Выполнить / вернуть |
| `Enter` | Открыть задачу |
| `1–4` | Приоритет |
| `Del` | Удалить |
| `Ctrl D` | Дублировать |
| `Ctrl 1–5` | Разделы |
| `Ctrl B` | Боковая панель |

## Разработка

Нужны [Node.js 22+](https://nodejs.org) и [Rust](https://rustup.rs).

```bash
npm install
npm run tauri dev     # приложение с горячей перезагрузкой
npm run dev           # только интерфейс в браузере (демо-данные, без Rust)
```

Проверки:

```bash
npm run check && npm test && cargo test --manifest-path src-tauri/Cargo.toml
```

## Сборка .exe

**Автоматически (GitHub Actions)** — `.github/workflows/build.yml`:
- каждый push в `main` прогоняет тесты и собирает `FlowDo.exe` (портативный) и `FlowDo_x.y.z_x64-setup.exe` (установщик) — они лежат в артефактах запуска;
- тег `v*` дополнительно публикует GitHub Release:

```bash
git tag v3.0.0 && git push --tags
```

**Локально на Windows:** `npm install && npm run tauri build` → `src-tauri/target/release/flowdo.exe` и установщик в `src-tauri/target/release/bundle/nsis/`.

Нужен Microsoft Edge WebView2 — он уже есть в Windows 10/11; установщик докачает его на старых системах.

## Иконка

Исходник — `assets/icon.svg`. После правки пересоберите все размеры (ico, icns, png):

```bash
npm run icons
```

## Где хранятся данные

`%APPDATA%\app.flowdo.desktop\flowdo.db` (SQLite). База FlowDo 2.x из `%APPDATA%\FlowDo\flowdo.db` копируется туда при первом запуске, оригинал не изменяется.

## Структура

```
src/                  интерфейс (Svelte 5 + TypeScript)
  lib/store.svelte.ts состояние, фильтры, счётчики, действия
  lib/parse.ts        умный ввод (+ тесты)
  lib/components/     компоненты
src-tauri/src/db.rs   SQLite, миграции, бизнес-логика (+ тесты)
src-tauri/src/lib.rs  команды Tauri, плагины, окно
```
