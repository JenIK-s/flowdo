# 🌊 FlowDo — туду-лист с характером

**Стек:** Python · FastAPI · SQLite · pywebview (нативное окно) · чистый JS

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
Откроется http://127.0.0.1:8000. Данные хранятся в `data/flowdo.db` (SQLite).

## Сборка .exe (Windows)
Запустите `build.bat` → результат в `dist\FlowDo.exe` (один файл, без консоли).
Данные exe-версии хранятся в `%APPDATA%\FlowDo\flowdo.db`. Нужен Microsoft Edge WebView2 (есть в Windows 10/11).
Без Windows: залейте проект на GitHub — workflow `.github/workflows/build.yml` соберёт exe и выложит артефактом.

## Новое в 2.0 (Enterprise-редакция)
- **Проекты** с боковой панелью и счётчиками (двойной клик — переименовать/удалить)
- **Подзадачи** с прогрессом, **аналитика** (KPI, график за 7 дней, разбивка по приоритетам)
- **Журнал действий** (аудит всех изменений)
- **Экспорт CSV/JSON** (CSV открывается в Excel) и **импорт JSON**
- Версионируемые **миграции БД** — данные версии 1.0 обновляются автоматически
- Логи в `flowdo.log`, автотесты: `pip install -r requirements-dev.txt && pytest`

## Возможности
- **Умный ввод:** `Купить молоко !срочно #дом @завтра` — приоритет, тег и срок разберутся сами
  (`!низкий|!высокий|!срочно`, `@сегодня|@завтра|@+3|@2026-12-31`)
- 4 приоритета с цветами, подсветка срочных и просроченных задач
- Редактирование (кнопка ✏️ или двойной клик): заметки, срок, теги, приоритет
- Drag & drop сортировка, сортировка по приоритету / сроку
- Фильтры, поиск, облако тегов
- Индикатор прогресса
- Отмена удаления, тёмная/светлая тема (по умолчанию как в системе)
- Горячие клавиши: `n` — новая задача, `/` — поиск, `t` — тема

## REST API
`GET/POST /api/tasks` · `PATCH/DELETE /api/tasks/{id}` · `POST /api/reorder` · `DELETE /api/completed`
Документация Swagger: `/docs`
